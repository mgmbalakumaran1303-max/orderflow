architecture (Zustand stores, repository/mock-db pattern, react-i18next, Tailwind v4 CSS-variable

## Remaining Issues

These were explicitly out of scope for this pass, deferred to keep the change reviewable, or require product/backend decisions this repo can't make on its own:

1. **Real backend integration** — everything above is still backed by the in-memory mock `db`/repository layer by design ("keep API-ready"); `apiClient.ts` (axios) exists but is not wired to any repository. Swapping to a real API means replacing each repository's body, not any UI code.
2. **Real printer/channel hardware, telephony, and maps** — Call/Navigate/Print/Reprint actions are still simulated (toast/mock latency), as they were before this change; there's no real printer driver, SMS/voice provider, or maps SDK to integrate against.
3. **`HelpCenterModal`** — still static, English-only content; not touched, since translating its long-form help copy into 5 languages was out of scope for this pass. Flagged here rather than silently left as a mixed-language surface.
4. **Full-page i18n audit** — Dashboard, Orders, Sidebar, common components, connection/AI-review/waiting-time strings are now fully localized (5 languages, verified). Some secondary pages (`ChannelsPage`, `DeliveryZonesPage`, `DevicesPage`, `MenuPage`, `RestaurantPage`, and parts of `UsersPage`'s modals) still have pre-existing hardcoded English strings that were out of this change's scope; they were not part of the requested Dashboard/Navigation change and touching them risked unrelated regressions.
5. **`src/theme/*.ts` token module** — confirmed dead code (not imported anywhere); the app actually themes via Tailwind v4 CSS variables in `src/styles/index.css`. Left as-is rather than removed or wired up, since neither was requested and removing it is a judgment call the user should make.
6. **Automated tests** — the project has no test runner configured (no Vitest/Jest/Playwright in `package.json`). Verification here was build/typecheck/lint plus manual browser testing; no automated regression suite was added, since introducing a whole test framework was outside this change request's scope.
7. **Accessibility** — modals trap focus and close on Escape (pre-existing), status is never color-only (icon+text used throughout), but a full WCAG audit (focus order, screen-reader labels on icon-only buttons, contrast in both themes) was not performed.
8. **Chunk size warning** — `npm run build` warns that `index-*.js` and `CartesianChart-*.js` (Recharts) exceed 500kB. Pre-existing, unrelated to this change; code-splitting Recharts further would be a separate performance task.
